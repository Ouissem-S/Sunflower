# Imagination

A webcam hand-tracking app that recreates the SpongeBob "Imagination" rainbow
meme in real life. Raise both hands with your thumbs together and a rainbow
arcs across the screen with sparkles and a wavy, rainbow-colored
"IMAGINATION" caption — just like the meme.

Built with OpenCV and MediaPipe Hands.

## Run

```
pip install -r requirements.txt
python main.py
```

Press `q` to quit.
